Forge Local Agent IDE — Code-OSS Windows runtime

Launch Forge.cmd or VSCodium.exe. Forge is included as a built-in Activity Bar
extension. Open a trusted folder, select the Forge icon, then choose a detected
Ollama, LM Studio, or llama.cpp model.

Forge.cmd keeps user data and installed extensions inside this portable folder.
The normal Extensions view uses Open VSX and can install local .vsix files from
its overflow menu. This build does not use or modify an existing VS Code profile.

The Code-OSS runtime is from the official VSCodium release and is distributed
under its included licenses. The Forge integration is local to this package.
